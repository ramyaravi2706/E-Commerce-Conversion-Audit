# CODTECH – Task 4
## E-Commerce Conversion Audit – ShopEase

### 📌 Project Overview

ShopEase is a mobile e-commerce application prototype created to evaluate the shopping experience and identify potential usability issues that may affect purchase conversion.

The project analyzes the complete shopping journey, from product discovery to checkout, and provides recommendations to improve usability and customer experience.

### ⚠️ Usability Issues Identified

| Screen | Identified Issue |
|---|---|
| Home | Product text readability can be improved |
| Product Details | Selection indicators need better visibility |
| My Cart | Quantity controls need improvement |
| Checkout | Payment options need clearer presentation |

### 💡 Recommendations

- Improve text readability and contrast.
- Highlight selected product options.
- Provide quantity adjustment controls.
- Improve cart management.
- Make payment methods more visible.
- Highlight the final payable amount.
- Maintain consistent spacing and alignment.
